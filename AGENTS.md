# ODC SDK Local Operating Notes

## No inventing information

- Never invent, guess, or present unverified information as fact.
- Do not fabricate metadata, accession numbers, identifiers, file paths,
  commands, results, citations, provenance, credentials, or completion claims.
- If a value is unknown, unavailable, or unverified, state that clearly;
  preserve it as `null` or `unknown` where the schema allows and identify what
  evidence would resolve it.
- Distinguish observed facts, user-provided information, assumptions, and
  inferences.
